Projeto criado para estudo de concorrência em Java.

Tecnologias:

✔ Java 17
✔ Spring Boot
✔ Semaphore
✔ ExecutorService
✔ Bootstrap 4
✔ H2 Database
✔ REST API

Objetivo:

Controlar o número de atendimentos simultâneos
através da classe Semaphore, simulando um cenário
real de gerenciamento de recursos limitados.
