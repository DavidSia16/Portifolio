Projeto  dashboard  de Vendas com PHP

Intuito de por em prática conhecimentos de Backend com tratamento de dados com banco de dados com MySql e entender a conexão com Frontend na prática.

Frontend desenvolvido sem uso de frameworks apenas html e css puro explorando 
funcionalidades do esqueleto na linguagem.

Backend com o básico para fixação de conhecimento com uso de variáveis , classes e métodos . Praticando a lógica usando os objetos de cada classe 
entendendo como trabalhar com banco de dados e o tratamento de casa valor que percorre o projeto.
